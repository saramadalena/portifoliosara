# Assets do portfólio

Pasta para upload de imagens e vídeos do portfólio pelo editor web do GitHub, sem Git LFS.

Sugestão de organização:

- `spdata/`
- `movee/`
- `arnaldo/`
- `polycare-freelas/`
- `site-portfolio/`

Use nomes curtos, sem acento, sem espaço e sem `&`.

Exemplos:

- `spdata-voce-capa.jpg`
- `minha-clinica-01.jpg`
- `movee-one-page-01.jpg`
- `arnaldo-rematricula-01.jpg`
- `polycare-logo-01.jpg`
- `site-portfolio-figma-01.jpg`
